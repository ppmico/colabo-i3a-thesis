# I3a collaboration - Thesis (Trabajo Fin de Grado)

This repository contains all the materials necessary to understand, reproduce, and build upon the research project, result of a collaboration with the I3A research group and the thesis presented for my degree. 

This repository contains the final version of the research paper in PDF format, along with every figure included in the paper. The directory **code** contains all the code, notebooks, and data necessary to reproduce the results presented in the paper.

## Reproducing the Results

To reproduce the results locally, you can follow these steps:

1. Clone this repository to your local machine.
2. Navigate to the `code` directory.
3. Ensure you have Docker installed.
4. Use the Colab Docker image to create a local runtime environment. You can find instructions on how to do this [here](https://research.google.com/colaboratory/local-runtimes.html).
5. Run the notebooks and scripts provided in the `code` directory.

All necessary dependencies will be taken care of using the Colab Docker image, ensuring a consistent and reproducible environment.

# Colaboración con el I3A - Trabajo Fin de Grado

Este repositorio contiene todos los materiales necesarios para comprender, reproducir y construir sobre el proyecto de investigación, resultado de la colaboración con el grupo de investigación I3A, que es también mi Trabajo Fin de Grado. 

Este repositorio contiene la versión final de la memoria en formato PDF, junto con toda figura incluida en la memoria. El directorio **code** contiene todo el código, notebooks y datos necesarios para reproducir los resultados presentados en el artículo.

## Reproduciendo los Resultados

Para reproducir los resultados localmente, puede seguir estos pasos:

1. Clone este repositorio a su máquina local.
2. Navegue al directorio `code`.
3. Asegúrese de tener Docker instalado.
4. Utilice la imagen Docker de Colab para crear un entorno de tiempo de ejecución local. Puede encontrar instrucciones sobre cómo hacer esto [aquí](https://research.google.com/colaboratory/local-runtimes.html).
5. Ejecute los notebooks y scripts proporcionados en el directorio `code`.

No será necesario gestionar las dependencias si se emplea la imagen Docker de Colab, lo que garantiza un entorno consistente y reproducible.
